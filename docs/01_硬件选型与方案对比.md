# 01-硬件选型与方案对比指南

本项目基于开源固件 [t2can-universal-unlock](https://github.com/hanliang33-cyber/t2can-universal-unlock) 进行全套硬件选型、设计评估与工程落地。该固件主要用于特斯拉（Tesla Model 3 / Model Y / Model YL）整车 CAN 总线的解耦、协议注入与高级辅助驾驶功能增强（包含 NAG 提醒消除、欧盟 R79 限速/变道解锁、自动打灯确认 Advanced EAP、S3XY 按键 BLE 联动等）。

---

## 一、 硬件核心系统架构

该固件的设计核心是**双通道高速 CAN 总线监听与帧注入（Dual-Channel CAN Gateway / Injection）**，结合 **Wi-Fi Web 仪表台** 与 **BLE 蓝牙 5.0 主从机通信**。

## 二、 主控硬件选型对比与评估

在选型时，针对双路 CAN、处理性能、车规抗干扰、体积及改装便捷性，主要有以下 4 种方案：

| 方案类别 | 推荐选型 | 优势 | 劣势 | 选型建议 |
| :--- | :--- | :--- | :--- | :--- |
| **官方标配推荐** | **LILYGO T-2CAN (ESP32-S3 标配版)** | ① 官方代码原生适配，引脚完全匹配无需修改；<br>② 集成 ESP32-S3 (16MB Flash, 8MB PSRAM)；<br>③ 板载 9~24V 宽压输入供电；<br>④ 尺寸小巧，带外壳与 IPEX 外接天线座。 | 默认板载两颗 120Ω 终端电阻，**上车前必须手工焊下拆除**。 | **强烈推荐（首选）**<br>开发周期最短，软硬件开箱即用。 |
| **替代选型 A** | **LILYGO T-2CAN-FD** | 硬件做工相近，集成 CAN-FD 控制器（MCP2518FD）。 | **固件软件不兼容**。<br>原固件依赖 `autowp-mcp2515` 库驱动 0x399/0x3FD 注入，直接刷入无法驱动 MCP2518。 | **不推荐**<br>除非自行重写 SPI CAN-FD 驱动底层。 |
| **替代选型 B** | **ESP32-S3-DevKitC-1 + 独立 MCP2515 模块 + 独立 CAN 模块** | 成本低（总计约 30~40 元），元器件采购极简，实验台验证方便。 | ① 飞线多，接插件容易在车载颠簸中松脱；<br>② 工业抗干扰（EMC）和地线隔离差；<br>③ 需额外加装 12V/16V 转 5V 降压板。 | **适合实验室台架研究**<br>不建议直接长期实车隐藏装配。 |
| **替代选型 C** | **自制一体化车规 PCB 模块** | ① 可彻底去掉 120Ω 终端，增加车规 TVS、共模电感；<br>② 可直接制作特斯拉专用对插接口，免除外部排线。 | 研发周期长，需打板并贴片焊接，单件打样成本高。 | **批量改装/商业化阶段推荐**。 |

## 三、 LILYGO T-2CAN 硬件规格与引脚定义

若选用 **LILYGO T-2CAN**，其物理引脚映射与固件 `pin_config.h` 的严格对应如下：

```c
// ==================== CAN B 通道 (ESP32-S3 TWAI 原生控制器) ====================
#define CAN_TX      7      // 连接板载 CAN B 收发器 TXD
#define CAN_RX      6      // 连接板载 CAN B 收发器 RXD

// ==================== 共享硬件 SPI 总线 (CAN A 控制) ====================
#define SPI_SCLK    12     // 对应 MCP2515 SCK
#define SPI_MOSI    11     // 对应 MCP2515 SI
#define SPI_MISO    13     // 对应 MCP2515 SO

// ==================== CAN A 通道 (MCP2515 外部 SPI 控制器) ====================
#define MCP2515_CS  10     // MCP2515 片选引脚 (Chip Select)
#define MCP2515_RST 9      // MCP2515 硬件复位引脚
// 晶振频率：板载 16MHz（代码固化 MCP_CLOCK = MCP_16MHZ）
// SPI 速率：10MHz（代码固化 MCP_SPI_HZ = 10000000）
```

## 四、 车载低压供电特性与降压选型

### 1. 特斯拉低压电气系统差异（关键风险）
* **2021 年及更早年份（Intel Atom 车机）**：采用传统的 **12V 铅酸蓄电池**，浮充电压约为 13.8V~14.4V。
* **2022 年及更新年份（AMD Ryzen 车机，如 Highland / Juniper / 新版 Y）**：全面升级为 **15.5V~16V 锂电池低压系统**，最高充电瞬态可能达到 16.5V 甚至有瞬态尖峰。

### 2. 电源转换方案建议
* **严禁用普通 12V 线性稳压芯片（如 7805）**：16V 压降到 3.3V/5V 发热量极大，会迅速热保护停机甚至烧毁。
* **推荐方案**：
  - 选用输入耐压 **≥ 36V** 的车规级异步/同步整流 DC-DC 降压模块（如基于 **LM2596HV**、**TPS5430**、**MP4560** 等芯片的模块）。
  - 在输入端串联一颗 **SS34 / SS54 肖特基二极管**（防止电源正负极反接）。
  - 在输入端并联一颗 **SMBJ24A / SMBJ28A 车规 TVS 二极管**（吸收车辆启动、电机启停产生的高压 Load Dump 浪涌脉冲）。
  - 输出稳定 **5.0V / 2A** 接入 T-2CAN 模块的 5V/VIN 引脚。

## 五、 特斯拉整车 CAN 取电与总线线束选型

为了不破坏原车线路（免破线），必须选购或自制**特斯拉专用无损对插线束（Y型线束）**：

| 取电/接线位置 | 对应车型 | 线束规格与接头形式 | 接入总线类型 | 特点与施工难度 |
| :--- | :--- | :--- | :--- | :--- |
| **副驾 A 柱下护板 / 踢脚板**<br>（X179 多总线诊断接口） | Model 3 / Model Y (全系推荐) | 特斯拉专用前排 X179 Y 型对插线束 | **Chassis CAN + Party CAN**<br>（或 Vehicle CAN） | **项目标准首选方案**。<br>同时汇聚底盘与 AP 私有总线，完美支撑 NAG 脱手消除与变道控制；撬开副驾右侧 A 柱及下护板即可对插。 |
| **中控扶手箱后部**<br>（后排出风口下方 X930） | Model 3 / Model Y (Legacy, 2019-2023) | 特斯拉 20 Pin / 26 Pin 蓝色对插接头 | **仅单路 Vehicle CAN** | **仅限单总线测试，无法解锁底盘 AP 功能**。<br>物理上不含 Chassis CAN，市售转接线仅 4 芯线，无法向底盘总线注入控制帧。 |
| **中央通道前部 (MCU 背后)** | Model Y L / 专车版本 | 车机专用多功能转接线束 | **Party CAN + VH CAN** | 专为 Model Y L 拓扑设计，需要拆卸中控屏幕后部护板。 |
